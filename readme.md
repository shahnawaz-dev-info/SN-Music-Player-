# 🎵 Music Player

A modern and responsive **Music Player** built using **HTML, CSS, and JavaScript**. This project provides a clean user interface with essential music playback controls and playlist functionality.

## 🌍 Live Preview
Experience Music Player live:

👉 Open Music Player https://shahnawaz-dev-info.github.io/SN-Music-Player-/
---

## 📌 Features


- 🎵 Play & Pause Music
- ⏮ Previous Song
- ⏭ Next Song
- 📜 Playlist Support
- 🖼 Album Cover Display
- 🎤 Song Title & Artist Name
- ⏱ Current Time & Total Duration
- 📊 Progress Bar (Seek Music)
- 🔊 Volume Control
- 🔄 Auto Play Next Song
- ⌨ Keyboard Shortcuts
- 📱 Responsive Design

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Add your music files inside the `songs` folder.
4. Add cover images inside the `images` folder.
5. Open `index.html` in your web browser.
